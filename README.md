# リスとドーナツ

埼玉県寄居町にある、生ドーナツ専門店「リスとドーナツ」のWebサイトです。

## プロジェクト概要

実在する生ドーナツ専門店「リスとドーナツ」のWebサイトを制作しました。

店舗の魅力や商品のこだわり、メニュー、営業日、アクセス情報などを掲載し、来店を検討しているお客様に必要な情報を分かりやすく届けることを目的としています。

また、InstagramやLINEへの導線を設け、最新情報の確認や商品の予約につながる構成にしました。

## 制作背景・目的

制作当時、店舗の情報発信はInstagramが中心でした。

口コミをきっかけにお店を知った方や、Instagramのアカウントを持っていない方にも店舗の情報を届けられるよう、Webサイトを制作しました。

また、Instagramからお店に興味を持った方が、商品の詳細や営業日、アクセス方法などを確認できる情報発信の場を設けることも目的としています。

## 制作時の工夫

### Instagramとの連携

店舗の最新情報や商品写真はInstagramで頻繁に更新している一方、Webサイトは頻繁な更新を必要としない運用を想定しました。

そのため、Instagramの投稿をWebサイト上に表示できる外部サービスを複数比較・検討し、Elfsightを採用しました。

これにより、Webサイト側で個別に写真を更新する手間を抑えながら、最新の投稿を閲覧できる構成にしました。

### 情報設計・導線

店舗の基本情報、商品のこだわり、メニュー、予約方法、アクセス情報などを整理し、初めてお店を知った方にも必要な情報が伝わる構成を意識しました。

また、InstagramやLINEへの導線を設け、情報収集から予約・問い合わせにつながるよう工夫しました。

## パフォーマンス改善

### 改善の背景・目的
公開後、Webサイトの読み込みに時間がかかることが気になり、ユーザーが快適に閲覧できるよう表示速度の改善に取り組みました。

### 実施した改善

- **画像のリサイズ・軽量化**
  - 画像の横幅を3,000pxから1,920pxに縮小
  - 画像のファイル容量を232KBまで削減
- **PageSpeed Insightsによる効果測定**
  - 改善前後のパフォーマンススコアや読み込み速度を比較
  - スマートフォン・PCそれぞれで計測し、改善箇所を確認

### 改善結果

PageSpeed Insightsによる計測結果は以下のとおりです。

- **パフォーマンススコア**

  - スマートフォン：58 → 63（+5）
  - PC：78 → 82（+4）

- **スマートフォンの読み込み速度**

  - LCP：37.1秒 → 15.5秒
  - Speed Index：13.8秒 → 6.1秒

画像の軽量化後、パフォーマンススコアと読み込み速度に改善が見られました。

### 今後の改善課題
- スマートフォンでのLCP（最大コンテンツ描画時間）のさらなる短縮
- 画像形式や読み込み方法の最適化
- CSS・JavaScriptの読み込みや処理の見直し

今後も計測と改善を繰り返し、表示速度とユーザー体験の向上を目指します。
